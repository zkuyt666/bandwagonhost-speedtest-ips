## 什么是搬瓦工 Bandwidth Test（机房测速）

**定义：** 搬瓦工 bandwidth test（带宽测试）是指通过 ping 目标机房的测试 IP、下载官方提供的测速文件，或访问 SpeedTest/LookingGlass 演示站，来衡量你本地网络与搬瓦工各数据中心之间的延迟、丢包率和实际下行速度的一套测试流程。

测试的核心指标有三个：

- **延迟（Latency）**：数据包从你本地出发、到达服务器再返回的时间，单位毫秒（ms），越低越好
- **丢包率（Packet Loss）**：发出的请求有多少比例丢失了，晚高峰如果超过 5% 就值得注意
- **实际下载速度**：通过下载测速文件（100MB / 500MB / 1000MB）测量实际可用带宽，与标称带宽往往有差距
